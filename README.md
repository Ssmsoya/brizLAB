# БРИЗ. — Beach Club & Sunbeds

Учебный одностраничный сервис бронирования 40 шезлонгов на интерактивной схеме пляжа. Визуальная концепция: premium coastal minimalism.

## Запуск

Откройте папку в VS Code и запустите **Live Server** на `index.html`. Либо из папки проекта выполните `python -m http.server 8000` и откройте `http://localhost:8000`. Открытие через `file://` не рекомендуется из-за ES-модулей.

## Технологии

HTML5, CSS3, Vanilla JavaScript (ES-модули), CSS Grid, Flexbox, localStorage. Без npm, backend, авторизации и платежей.

## Возможности

- 40 шезлонгов в зонах A/B/C/D, 2 технически недоступных места.
- Выбор до 6 мест, синхронные схема и список, фильтры по зоне, цене, доступности, зонтику и VIP.
- Даты от сегодня до 30 дней вперёд; утро, день, вечер и полный день. Короткие сеансы — 60% дневной цены.
- Проверка пересечения временных интервалов; демонстрационные занятые места на ближайшие дни.
- Подбор соседних мест в одном ряду; пакеты и дополнительные услуги; расчёт суммы.
- Проверка формы, защита от повторного подтверждения, сохранение, отмена, фильтрация бронирований.
- Адаптивная вёрстка, клавиатурная навигация, aria-label, prefers-reduced-motion.

## Структура

- `index.html` — семантическая разметка.
- `style.css` — адаптивное оформление и анимации.
- `data.js` — тарифы, места, услуги, пакеты и демо-брони.
- `booking.js` — расчёт, доступность, пересечения, валидация.
- `storage.js` — безопасная загрузка, запись и сброс localStorage.
- `main.js` — интерфейс и обработчики событий.
- `assets/` — четыре предоставленных визуальных референса.

## Бронирование

Выберите будущую дату и сеанс, отметьте места на карте или в списке, затем нажмите «Продолжить». Добавьте пакет и услуги, заполните имя и телефон, примите правила, подтвердите. Бронь появится в «Моих бронированиях». Отмена до начала сеанса освободит места на соответствующий период. Занятость определяется условием `start1 < end2 && start2 < end1`.

## Публикация на GitHub Pages

Создайте репозиторий, загрузите содержимое этой папки в корень, откройте **Settings → Pages → Deploy from a branch → main / root → Save**. После публикации проверьте сайт по выданной ссылке. Публикация и репозиторий автоматически не создаются.

## Ограничения

**Учебное демо:** данные сохраняются только в браузере (`beachClubBookings`), нет реальной оплаты, услуг, синхронизации устройств или защиты от одновременных бронирований разных пользователей. Контактные данные также остаются только в localStorage; не вводите реальные чувствительные сведения. Для анимированного моря используется CSS-эффект поверх локального изображения, не видео и не физическая симуляция воды.

## Исправления интерфейса

`index.html` теперь запускает `app.js` как обычный отложенный скрипт. Это позволяет открыть страницу напрямую из папки без ограничений ES-модулей. Исходные `data.js`, `booking.js`, `storage.js` и `main.js` сохранены для чтения и редактирования; после их изменения необходимо пересобрать `app.js`.

Сеансы: утро 08–12 (4 часа), день 12–16 (4 часа), вечер 16–20 (4 часа), полный день 08–20 (12 часов). Бронирование относится к конкретному дню и интервалу.

Анимация прибоя — стилизованная CSS/SVG-анимация, а не фотореалистичная симуляция или видеосъёмка.
